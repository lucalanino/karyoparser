Loss derivation is deliberately limited to simple single-junction `der(a)t(a;b)`; multi-junction chains and three-way `t(a;b;c)` ders are flagged unbalanced but derive no loss (fail-safe -- no guessed geometry). Remaining (all out-of-scope for now, acknowledged): (a) widen curated `unbal_loss_*` arm set or expose all arms; (b) copy-number-aware GAIN derivation (needs whole-karyotype reasoning); (c) a der of a three-way `t(a;b;c)` (e.g. `der(9)t(9;22;11)`) currently gets NO balanced/unbalanced flag at all, since the two-partner regex can't match a 3-chromosome junction -- would need a separate code path; (d) reciprocal ders split across an `idem` subclone (e.g. `der(5)t(5;17)/idem,der(17)t(5;17)`) report `unbalanced=1` only (defensible: the stemline clone really is unbalanced) but miss the `balanced=1` that clone 2's idem-inherited pair implies -- a proper fix needs `idem` token-expansion, which the package does not do anywhere. See `classify_translocation_balance()`/`derive_unbalanced_loss()` in `R/parse_karyo.R`.
- **[P3] Mosaicism `mos` prefix (out of scope, acknowledged)**: Karyotypes written with a leading `mos` mosaicism prefix (e.g. `mos 47,XXY[10]/46,XY[5]`) are flagged `no_chromosome_count` (the string does not start with a digit) and left unfixable. Stripping/parsing the `mos` prefix is a deliberate non-goal for now; revisit only if mosaic notation needs first-class handling.
- **[P3] Non-clonal single-cell abnormalities `ncSCA` (out of scope, acknowledged)**: Karyotypes carrying an `ncSCA` token (e.g. `46,XX(ncSCA)[1]//46,XY[19]`, `44~102,ncSCA[17]//46,XY[5]`) are left unfixable (`no_sex_complement`, since `ncSCA` glues to / replaces the sex complement). Parsing non-clonal single-cell abnormalities is a deliberate non-goal.
- **[P3] Constitutional abnormalities (out of scope, acknowledged)**: Sex complements with a constitutional `c` suffix (e.g. `47,XXYc`, `47,XXXc?`) are deliberately not parsed -- they are flagged `constitutional_sex_complement` (unfixable) by `validate_karyotypes()` so they are no longer mislabelled `no_sex_complement`. Parsing constitutional/germline abnormalities (vs acquired) is a non-goal for now; revisit only if downstream needs to distinguish them.
